# AICY SPICE 🌶️

AICY SPICE is a premium spice store website showcasing authentic Kerala spices with a modern and user-friendly shopping experience.

## Technologies Used
- HTML5
- Tailwind CSS

## Features
- Premium spice store interface
- Spice product presentation
- Image-based product sections
- Clean and user-friendly design

## Project Structure
- `erchi.html` – Main website page
- `img/` – Project images

## Purpose
This project was developed to practise frontend web development and create a modern online spice store experience.
